# Progress — engine

## Done

**Phase 3 — model layer, masking, OCR, AI and real API functions (2026-11-15), branch `feat/engine`.** `ENGINE_VERSION` 0.3.0.

- **Model stage (§7, `src/model.ts`):** memoised `getModel()` over `loadModel()` (a throwing loader counts as no model); `safePredict()` — a model that throws or returns junk makes the layer unavailable and marks the stage `failed`, never fails the scan; MODEL_PATTERN from positive contributions: spans merged when they overlap or sit within one character, top 6 by summed value, expanded to word boundaries. Layer `available: false` and stage `skipped` when no model loads. Tested with a fake `TextModel` (C's stub still returns null on this branch).
- **`maskPII` (§11):** URLs → `https://<registrable domain>/[PATH]`; emails → `[EMAIL]`; UPI IDs → `[UPI_ID]`; 16-digit cards → `[NUMBER]`; 12-digit Aadhaar-like groups and PAN → `[ID_NUMBER]`; phones → `[PHONE]`; other 9–18 digit runs → `[NUMBER]`; names after Dear/Mr/Mrs/Ms/Shri/Smt/श्री/श्रीमती/प्रिय → `[NAME]` (not "Dear Customer", "प्रिय ग्राहक"). Amounts after ₹/Rs/INR and brand names survive. Tests for every pattern.
- **OCR (`@akshi/engine/browser`, §10):** tesseract.js **7.0.0** (pinned exactly; core 7.0.0), LSTM-only, one worker created lazily and reused, `reinitialize` when the language set changes (requested UI languages + `eng` always), `workerBlobURL: false`, `gzip: true`; images wider than 1600 px are downscaled (OffscreenCanvas, canvas fallback); progress 0–1 (loading 0–0.5, recognition 0.5–1); word boxes with `start`/`end` into the normalised OCR text (each word normalised and joined with one space, so `normalizeText(ocr.text) === ocr.text`); `analyze({ kind: 'image', ocr })` maps every box to the signals whose spans overlap it. Box coordinates are in `OcrResult.width × height` (the downscaled image). Also exported from `@akshi/engine/browser`: `setOcrAssetBase(base)`, `terminateOcr()`, `buildOcrResult`, `downscaleSize`. The engine no longer imports `@akshi/contracts/fixtures` (B's bundle request).
- **OCR assets** in `packages/engine/assets/`, built by `npm run ocr-assets` (`scripts/ocr-assets.ts`) and committed:
  - `tesseract/worker.min.js` — tesseract.js 7.0.0
  - `tesseract/tesseract-core-relaxedsimd-lstm.wasm.js`, `tesseract/tesseract-core-simd-lstm.wasm.js`, `tesseract/tesseract-core-lstm.wasm.js` — tesseract.js-core 7.0.0 (the worker picks one by CPU support; ~3.9 MB each, wasm embedded)
  - `tessdata/eng.traineddata.gz` (1.96 MB), `tessdata/hin.traineddata.gz` (0.92 MB), `tessdata/tel.traineddata.gz` (1.23 MB), `tessdata/ben.traineddata.gz` (0.55 MB) — github.com/tesseract-ocr/tessdata_fast at commit `87416418`, gzipped (Apache-2.0)
  - `MANIFEST.json` — versions, sources, sizes and SHA-256 of every file
- **AI second opinion, engine side (`src/ai.ts`):** when `options.cloudAI === true`, `layers.ai !== false` and the device is online, the masked text (≤ 4,000 chars), rule signal ids, local category and local score go to `/api/ai/analyze` (client timeout 20 s). The reply is re-validated; `likelihood` is blended per §8.2 (`(1 − aiBlend)·base + aiBlend·ai`, capped at base + 15); one AI_FLAG signal per red flag (`source: 'ai'`, detail = the AI's reason, display weight 0.25) with its quote mapped back to the original text (mask tags matched by shape); AI category used when it agrees with the rules or the model (§8.4); the AI explanation replaces the template (the QR payee line stays first; the PIN statement wins for receive-with-PIN traps); `aiUsed`, `aiProvider`, `offline: false`; stage `ai` is `done` / `failed` / `skipped`. Any failure is silent.
- **`/api/ai/analyze` (§12.1):** zod-validated body (maskedText ≤ 4,000; 64 KB body cap); 20/min/IP; AI SDK 7 `generateObject` with a zod schema, temperature 0.2, ≤ 500 output tokens, no SDK retries, 8 s per provider; Groq (`GROQ_API_KEY` + `GROQ_MODEL`) then Gemini (`GEMINI_API_KEY` + `GEMINI_MODEL`), falling back on 429, timeout, invalid output or any error; 503 `upstream_unavailable` (504 `timeout` when both time out; 503 when nothing is configured). The message sits inside `<message>` tags with tag-like sequences stripped; system prompt per SPEC_A §12.1; output cleaned (exact-substring quotes, max 5; likelihood clamped; unknown category → null; explanation ≤ 60 words). Logs `{route, provider, ms, status}` only.
- **`/api/expand` (§12.2):** http/https, ≤ 2,048 chars, no credentials, ports 80/443 only. Every hop resolves the host (all addresses) and refuses private/reserved IPv4 (0/8, 10/8, 100.64/10, 127/8, 169.254/16, 172.16/12, 192.0.0/24, 192.0.2/24, 192.88.99/24, 192.168/16, 198.18/15, 198.51.100/24, 203.0.113/24, 224/4, 240/4) and IPv6 (::, ::1, fc00::/7, fe80::/10, ff00::/8, 2001:db8::/32, IPv4-mapped/compatible, NAT64 64:ff9b::/96, 6to4 with a private inner address). Decimal/octal/hex IPv4 hosts are normalised by `URL` first. The real fetch uses an undici `Agent` whose connect-time lookup applies the same rule, so DNS rebinding cannot slip through. `redirect: 'manual'`, HEAD then GET on 403/405/501 (headers only, body never read), 3 s per hop, max 5 hops (`truncated: true`), `error` codes `blocked_private_address`, `bad_port`, `dns_failed`, `timeout`, `unreachable`. 10-minute cache; 60/min/IP.
- **`/api/domain-age` (§12.3):** registrable domains only (400 otherwise); `https://rdap.org/domain/<d>`, 5 s timeout; registration event → `registered` + `ageDays`; registrar from the vCard `fn`; `{ domain, error: 'unavailable' }` for registries without RDAP, errors or no date; cache 1 h (failures 10 min); 60/min/IP.
- **`/api/health` (§12.6):** `ai.groq` / `ai.gemini` true only when both key and model name are set; values never returned. In-memory sliding-window limiter per IP and route (ai 20, ask 20, expand 60, domain-age 60 per minute; best effort per instance). `/api/ask` is rate-limited too (its LLM rewrite is P4).
- Server code is in `api/_lib/`, API tests in `api/_test/` (Vercel does not deploy `_`-prefixed paths as functions); relative imports in `api/` use explicit `.js` extensions so the compiled ESM resolves. Root Vitest config has an `api` project.
- **`scripts/dev-api.ts`** serves health, ai/analyze, expand, domain-age and ask on :3001 and loads `.env` (checked with a temporary dummy `.env`: health reported `groq: true`; all routes answered).
- `"sideEffects": false` in `@akshi/contracts` and `@akshi/engine` (B's request). Lexicon additions: "stay on the video call", "parcel with drugs", "kyc fee" and similar.

- **Deviations from SPEC_A (documented in code):** single-item inputs leave the rules layer out of the §8.2 average; lookalike distance only for tokens ≥ 5 letters; identity signals in the rules layer; website-QR floor 40; phone-based BRAND_MISMATCH needs pressure; ASKS_OTP floor 45; AI_FLAG display weight 0.25 (the AI layer itself is blended, not added to rules).
- **AI_FLAG signals repeat the id** (one per red flag, as §5.2 says), so `signals` can contain several entries with `id: 'AI_FLAG'` — UI lists must not key by `id` alone.
- **Rate limits and caches are per function instance** (in memory); a determined client can exceed them across instances. Good enough for the demo; Upstash would be the fix (P2 item M8.6).
- **Vercel compiling `api/*.ts` that import workspace packages exporting `.ts` source** is still unverified — check on the first preview deploy after Merge 1; fallback is bundling `api/` with esbuild in the build command.
- **OCR asset size:** 12 MB of tesseract core (three variants) + 4.7 MB tessdata in git. Only one core variant and the chosen languages are downloaded by a browser at run time.
- Carried: tool escaping quirks on this laptop, root scripts use `--workspaces --if-present`, TypeScript `~6.0.3`, `npm audit` minimatch advisory via typescript-eslint ≤ 8.72.2 (no fixed release yet, lint-only), `claimedAs` keyword-based, newline collapse in chat/email text.
